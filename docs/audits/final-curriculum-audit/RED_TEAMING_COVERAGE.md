# Defensive red-teaming coverage

**Historical coverage.** This matrix describes the original audit snapshot. [Batch 1](REMEDIATION_BATCH_1.md) corrected the finding lifecycle, wrong-resource classification and denominator handling. [Batch 2](REMEDIATION_BATCH_2.md#f-004--exercise-a-defense-across-retained-history) added the scoped offline retained-history control. The matrix preserves the original coverage ratings.

**Readiness.** The core can teach a defensive assessment of prewritten evidence in a fictional environment. It can teach threat modeling, independent verification, denial and exposure measurements, remediation and regression reporting. It does not yet give enough transfer evidence to certify an independent assessment of a stateful system. M12's authoritative scope describes fixed benign fixtures and mock effects, so a lack of scanner execution is within scope. The gap is the transition from reviewing a capture to running and checking a safe control. [Authoritative M12 scope](../../../MASTER_CURRICULUM.md#L989)

**Classification.** Fully covered means an explanation plus a worked or assessed application adequate for the stated scope. Partially covered means narrower fixture evidence, a concept without independent practice, or a verified limitation. Missing means the capability is not taught as a comparable skill in the reviewed sequence. Covered elsewhere with valid prerequisites means an accessible prior lesson, explicit recommended or conditional link, or advanced elective supplies the specified component. That classification does not make elective work a core requirement.

## What to improve first

Resolve the reporting and action-scope defects before adding coverage. Then extend the existing lab with an inert, no-network stateful fixture that observes role, source and application state before and after one defensive control. Include a permitted match and missing evidence. A printable report must let a reviewer recover the planned IDs independently of dispatched records and distinguish observed effects from missing evidence. Maintain the existing written authorization and data-minimization boundaries. Real targets and real payloads are outside this instructional scope.
