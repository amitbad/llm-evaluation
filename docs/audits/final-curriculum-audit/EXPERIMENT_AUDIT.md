## Fresh lesson replay

- **Coverage.** Extracted all 346 standalone fenced Python programs across the 53 lesson sources. Parsed each program and reviewed imports and calls before execution. Ran with Python 3.12.7 in fresh isolated interpreter processes, no inherited provider keys, using scratch paths. M14 reads explicitly named repo fixtures. M14 decision and timing outputs went to new temporary paths. M17's optional trusted subprocess performance mode was outside the default replay.
- **Results.** 349 invocations, 348 exits with code zero and one intentional injected-failure exit. All 343 standalone programs outside M14 matched the first adjacent documented text transcript after trimming surrounding whitespace. Programs with expected-failure verdicts were compared as output, rather than treated as runtime failures.
- **M14-T01.** TC10 baseline emitted `FAIL_MISSING_REQUIRED_SEARCH`. Repair emitted `PASS_SEARCH_AND_SAFE_ESCALATION` after lookup and search. Injected lookup error exited 1 with `Lab stopped: Account lookup failed. Finalization stopped.` Used `--no-export`. No trace IDs were emitted.
- **M14-T02.** Used the workbook loader in an existing environment with openpyxl. Its 24-line output matched the published transcript, including the 31/49 workbook result and the synthetic monitoring decisions. The audit JSON was written outside the repository.
- **M14-T03.** Saved measurements reproduced all 13 output lines. A fresh local burst produced new timings and returned `ACCEPT CHANGE IN THIS FIXTURE`. Timing variation is expected. This verifies a teaching fixture running on an audit machine, not a hosted SLO.
- **Counterfactual checks.** Exercised M12's missing dispatch, alternative denial wording, wrong-order executed fixture and empty verification lifecycle, plus M18-T01's reference-only edit. Details and consequences are in [the findings](FINDINGS.md).
- **Limits.** This pass did not execute every learner-edit variant, optional shell or YAML walkthrough, remote evaluator, hosted CI, Langfuse export, or browser editor. The chapter text, selected variants and saved data were inspected. Source-level transcript matches establish reproducibility for the cases tested. Instructor, browser, human-review and production evidence are separate.
