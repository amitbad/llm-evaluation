# Topic scorecard

Scores evaluate the lesson source against its authoritative topic entry at the original audit snapshot. The auditor scored the locally authored M18-T01 draft. The public outline available at that time had no equivalent experiment or assessment to score. Scores and line references describe the reviewed versions. See the [findings register](FINDINGS.md) for remediation links and [current release progress](../../../PROGRESS.md) for the public recheck. The scorecard does not record learner performance or human teaching approval.

| Dimension | What the reviewer looked for |
|---|---|
| O · Objectives | Required concepts, demonstrated behavior, outputs and completion checkpoint |
| T · Technical correctness | Correct formulas and claims, reproducible examples, defensible exceptions and safeguards |
| B · Beginner clarity | Concrete example first, vocabulary and tools introduced when needed, stated background and transitions |
| P · Practical depth | Runnable work, predictions, controlled changes, meaningful negative or missing-evidence cases |
| A · Assessment | Independent work, answer or verification criteria, interpretation and a decision |
| R · Real-world readiness | Trust boundaries, assumptions, authentic artifacts where useful, failure handling and stated limits |

**Scale across each dimension.** 0 absent, 1 named only, 2 introduced with insufficient support, 3 usable with a material gap, 4 strong with a remaining verification or transfer limit, 5 complete for the stated instructional scope. Unrun optional live components are evidence limits. A fixture can receive 5 for a skill it actually models and tests. A 5 establishes neither human teaching approval nor externally measured effectiveness. The final column records fresh local evidence and distinguishes it from data and code read during the audit.
