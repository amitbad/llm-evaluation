## Facilitator script

Read the task aloud once. Ask the learner to think aloud and use the site instructions. Observe before helping. If the learner cannot continue, record the first intervention and whether they then proceed. Keep actual output and explanations distinct from expected results.

| Step | Give the learner this task | Observe and record |
| --- | --- | --- |
| 1 · Onboard | “Find where a complete beginner should start. Tell me what preparation applies to you.” | Can they reach preparation and describe one needed checkpoint? Record hesitation, unexpected links and prompts for help. |
| 2 · Choose a path | “Open Quick Learning, choose A and find the first lesson, M01-T01.” | Can they identify the chosen path, first topic and Next control unaided? Record time and wrong turns. |
| 3 · Run | “Find Step 1, copy it, open the editor and compare the run to the lesson.” | Capture whether the learner found copy feedback, pasted the code intact, ran it and matched the five-line output. |
| 4 · Predict and change | “Predict what changes if the tool result is printed before the lookup. Make only that change, rerun and explain the result.” | Expected evidence is reordered lookup/result lines and an explanation that successful execution can still show invalid order. Record prediction before running and the actual explanation. |
| 5 · Save and resume | “Mark the lesson complete, reload, then find Continue Learning. Verify completion in Complete Course.” | Expect persisted completion in both modes and the first unfinished required topic. Record completion and resume destinations. |
| 6 · Retain progress | “Export your progress. Tell me how you would recover it in another browser.” | Learner can locate the backup and distinguish preview from applying a restore. Use an isolated profile for any restore attempt. |

For the terminal handoff from the original readiness checklist, schedule a separate short session after the learner completes the relevant preparation. Give them a fresh checkout and ask them to use the preparation packet to identify the checkout root and fixture, then run the M14-T01 offline replay. Observe whether they can interpret `FAIL_MISSING_REQUIRED_SEARCH` despite a successful program exit. Use the existing lesson instructions and `--no-export`. A transcript-only fallback can demonstrate interpretation. Record the independent run separately.
