Phase 2 — Evaluation Techniques

Test 3: Automated Metrics

First automated evaluation. Moving from manual scoring to math-based metrics — BLEU and ROUGE — to compare model outputs against a reference answer.

📁 phase-2-evaluation-techniques/test3_bleu_score_evaluation.py

What We Tested

A summarisation task on a sample AI text. All 4 models summarised the same passage. We then measured how closely each summary matched a reference summary using two automated metrics.

What BLEU and ROUGE Mean (Simply)

MetricWhat It MeasuresThink of It As
BLEUHow many exact word phrases from the model output match the referenceWord-for-word overlap — like checking if the model used the same phrases
ROUGE-1Single word overlap between output and referenceDid the model use the same words at all?
ROUGE-2Two-word phrase overlapDid the model use the same two-word combinations?
ROUGE-LLongest matching sequence of words in orderDid the model follow a similar sentence structure?
Higher scores mean closer to the reference — but closer is not always better. A model can be factually correct in completely different words and score low. These metrics measure similarity, not quality.

Key Learnings

  • deepseek scored highest but was slowest. Best similarity to reference (BLEU 24.61, ROUGE-1 0.67), but took 85 seconds. There is a trade-off between quality and speed.
  • llama scored lower because it added a preamble. It started with "Here is a summary of the text in 2-3 sentences:" — those words are not in the reference, which pulls the score down even though the actual summary was accurate. This reveals a limitation of these metrics.
  • gemma scored lowest despite a reasonable summary. It added "Let me know if you'd like me to elaborate" at the end — again, not in the reference. The metric penalises additions, not just errors.
  • These metrics cannot evaluate meaning. A model could say "AI enables machines to think" and another could say "Artificial intelligence allows computers to perform intelligent tasks" — similar meaning, low overlap score. That is why we move to semantic evaluation next.
  • Automated metrics remove human bias. Manual scoring depends on who is reading. BLEU and ROUGE give the same number every time for the same inputs — fully repeatable and comparable across runs.

What This Evaluation is Called

BLEU (Bilingual Evaluation Understudy) and ROUGE (Recall-Oriented Understudy for Gisting Evaluation) are reference-based automated metrics. They come from the field of machine translation and text summarisation research. They are fast, cheap, and objective — but they measure surface similarity, not semantic correctness.
