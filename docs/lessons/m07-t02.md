## What You Will Learn

- Translate pass rates into counts and distinguish a percentage-point change from a relative change.
- Use Wilson intervals to describe uncertainty around a binary pass rate and understand how sample size and confidence level affect precision.
- Compare two configurations on matched cases with an exact paired test and a whole-pair bootstrap.
- Plan a comparison around a meaningful effect, then combine statistical evidence, coverage, and critical policy checks in a release recommendation.

## Why This Lesson Matters

At Harbor Leaf Market, someone brings two numbers to the release meeting: 80% for the current refund assistant, A, and 85% for the proposed upgrade, B. Before voting, ask for the case list. If both assistants faced twenty questions, one extra pass could explain the whole gain. Find that extra pass, look for cases B got worse, and check whether either reply would send a customer past the real refund deadline.

The company, replies, verdicts, and thresholds in this lesson are fictional. We keep the earlier policy `refund-1`: “Refund requests are allowed through calendar day 30 after delivery with a valid receipt.” The item is an eligible unused online purchase, and day 30 is included. The statistic we measure is the fraction of judged cases that pass the case rubric.

## Beginner Explanation

### Ask what each percentage counted

Suppose A passed 16 of 20 and B passed 17 of the same 20. One more pass is enough to move from 80% to 85%. Subtract 80 from 85 to get **five percentage points**. Divide that gain by A’s 80% to get a **6.25% relative improvement** in the pass rate. These are two ways to describe the observed **effect size**, the size of the measured difference.

If you sampled a new group of customers, the questions and outcomes could differ. This is **sampling variability**. An observed 85% describes the cases counted in one evaluation. It estimates performance for a target population only to the extent that those cases and their labels represent it. Rerating a frozen reply tells you how the judge behaves on that reply. It does not add another sampled customer or question.

If A and B use different case sets, differences in question difficulty can move the rates. Ask for the case IDs, planned and valid counts, response records, and rubric version before comparing the headline results. Repeated variants from one customer or conversation can be correlated. In that setting, count and resample the independent groups, keeping their replies together.

### Give the single pass rate an interval

Three teams each report 80%. One counted 8 of 10, another 80 of 100, and the third 800 of 1,000. Each has a different number of independent binary observations. That number is its **sample size**. Eight passes give a rougher picture than eight hundred if both sets are sampled well. A large set drawn from easy cases can still miss the kinds of question you need to judge.

Imagine a new Harbor Leaf team taking a fresh sample each week. Each team draws the same number of suitable cases and marks two limits around its observed rate. Those limits form a **confidence interval**. If you could draw one line at the fixed underlying rate, some of the weekly intervals would cross that line and others would miss it. The 95% label describes how often the procedure aims to cross that line over many such samples, under its assumptions. Wilson coverage is approximate. The two limits in this week’s report are already fixed.

Here is how we get the two endpoints. Let `k` be the number of passes, `n` the number of scored cases, and `p = k/n` the observed fraction. Let `z` be the normal cutoff chosen for the confidence level, for example 1.96 for 95%. A normal cutoff is measured in standard deviations from zero under a standard bell-shaped reference curve. For 90% it is about 1.645, and for 99% about 2.576. The larger cutoff reaches farther into the tails of that curve.

For 8 of 10, `p` is 0.8 and `z²/n` is about 0.384. The Wilson center shifts inward to about 0.717. Its half-width is about 0.227. Subtract and add that half-width to get about 0.490 and 0.943. Keep full precision until the end. The calculation adjusts both the center and width and gives useful limits even when a small sample has zero or all passes. [NIST, Wilson confidence limits](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

In symbols, the common divisor is `d = 1 + z²/n`. The center is `(p + z²/(2n)) / d`. The half-width is `z × sqrt(p(1−p)/n + z²/(4n²)) / d`. The term `p(1−p)` reflects how much 0/1 outcomes can vary and `sqrt` turns squared uncertainty back into pass-rate units. The extra terms come from solving the Wilson score rule. They keep the two limits meaningful when `p` is near zero or one. Predict what happens to the width when `n` grows at the same observed rate. Then check it in Step 2.

At the same sample size, a higher confidence level usually makes the interval wider. A 99% procedure aims to miss the underlying rate less often, so it leaves itself more room. Compare the actual widths in Step 3. Confidence levels describe the interval method. They do not account for bias in deciding which questions go into the evaluation.

### Pair the answers before counting changes

| Case | A | B | What changed |
| --- | --- | --- | --- |
| C01 | PASS | PASS | Neither wins this case. |
| C02 | FAIL | PASS | B gains one pass. |
| C03 | PASS | FAIL | B loses one pass. |
| C04 | FAIL | FAIL | Neither wins this case. |

The matched case is the unit. Rows where the outcomes agree are **concordant**. Rows that differ are **discordant**. The B-only and A-only rows give the direction of the changes. B gained one and lost one. Its observed effect on these four cases is (1 − 1) ÷ 4 = 0. A paired comparison keeps this match. An independent-samples test would discard it by treating the observations as if A and B got separate, unrelated cases. Use that analysis only when the sampling design actually supports it.

Keep the same small example in mind when estimating uncertainty in the difference. Write the case IDs on four cards. A draw might be C01, C02, C02, C04. Take both outcomes each time you draw a card. That draw has two B-only passes and no A-only passes, for an effect of +50 points. Another draw, C01, C03, C03, C04, gives −50 points. Returning the card after every draw is called sampling **with replacement**.

Repeat this draw many times, always drawing the same number of whole pairs as in the original sample. Sort the new differences and use the 2.5% and 97.5% positions for an approximate 95% **paired bootstrap interval**. This estimates uncertainty by resampling the observed cases. It needs representative independent case units and can be unreliable with very small or nearly degenerate data. In the lab, independently drawing A and B would break the link between outcomes on the same case. You will calculate that independent-design approximation as a contrast, with its different assumptions printed beside it.

### Ask how unusual the discordant counts are

Suppose three discordant cases favor B and two favor A. If neither configuration has an advantage, each discordant direction should be equally likely. This is the **null hypothesis** of equal marginal pass probabilities. The two-sided **alternative** allows either configuration to win more often on discordant cases. Conditional on five discordant cases under the null, imagine five independent fair flips giving the direction. This is the case-level swap intuition of a paired test. A tied case adds no evidence about direction.

Use the smaller discordant count, two, as the **test statistic**. Of the 32 equally likely flip sequences, 1 has zero B wins, 5 have one, and 10 have two. The opposite tail has the same size. The two-sided **exact McNemar test** adds both tails to get 2 × (1 + 5 + 10)/32 = 1. A **p-value** is the probability, under the null and test assumptions, of results at least as extreme as the one observed. It gives no probability that the null is true. [Statsmodels, exact binomial McNemar test](https://www.statsmodels.org/dev/_modules/statsmodels/stats/contingency_tables.html)

Choose the **significance level**, often written `alpha`, before seeing results. This fictional plan uses 0.05. Reject the equal-probability null when the exact p-value is at most 0.05. If you do not reject, the test may have little information. It gives no guarantee of equality. With no discordant pairs the code reports p = 1 and flags that there was no directional evidence. The test assumes independent pairs, consistent binary scoring, and an analysis fixed before looking at outcomes.

The Wilson intervals describe each configuration’s rate. The whole-pair interval describes the gain. The exact paired test asks how unusual the direction count is under equality. Comparing two marginal interval pictures for overlap does not perform this test. A percentile bootstrap and an exact probability test may also differ near a threshold because they use different procedures.

### Plan for a useful result

Suppose a one-point gain would only prevent one error per 100 questions, while changing the system would add manual review on ten. Decide whether that is worthwhile and which error types matter. For Harbor Leaf, getting a deadline wrong can outweigh gains on routine replies. Set a **practical threshold** for an observed gain before testing and require a separate critical policy review. A small p-value alone says little about business value or safety.

For planning, write down the baseline pass rate, a plausible improvement, the desired false-positive level, and the chance you want of detecting a specified real improvement. That chance is **power**. The **minimum detectable effect** is the smallest effect the proposed design is intended to detect with that power. It depends on sample size and expected variability. For paired tests, estimate how often changes go in both directions. A five-point gain could come from 7% B-only and 2% A-only cases, or 22% B-only and 17% A-only. The same net gain then comes with different disagreement rates. Use estimates from separate pilot cases and plan using the paired design.

If a pilot suggests 10% discordance and a net gain of 5 points, that implies 7.5% B-only and 2.5% A-only. Simulate many paired samples at a candidate size using those probabilities, run the exact test on each sample, and count how often it rejects at the planned alpha. Increase the size until that fraction meets your power goal, checking other plausible disagreement rates as well. This is planning under explicit assumptions, not a guarantee.

Step 6 does a narrower job. It finds the first sample size on a declared grid that gives a single-rate Wilson interval with a target width, assuming the observed rate stays at 80%. It is a **precision calculation**, with no promise of a particular power for the paired test. More distinct cases can improve precision under good sampling. More copies of old cases cannot replace a representative evaluation set.

If ten unrelated null comparisons each have a 5% false-positive chance, the chance at least one triggers is `1 − 0.95¹⁰`, about 40%. That illustration assumes independent comparisons which real model trials may not satisfy. Choose the primary comparison and decision rules in advance, record the configurations tried, and validate any selected model on a fresh holdout. If several claims are primary, plan how to handle the family of tests before drawing conclusions.

Even a good calculation cannot correct changing rubrics, judge mistakes, correlated cases, or an unrepresentative sample. Repeated use of a holdout can tune you to it. Model settings or live generation can also change between runs. Report invalid outcomes, missing slices, version differences, and deployment risks the evaluation did not cover.

## Worked Demonstration

### Example 1. Same rate, different precision

**User question.** Which 80% report gives the tighter estimate for refund-case performance?

**Approved reference.** Each report uses the same binary refund rubric and a sample of distinct cases drawn from the same target population in this teaching example.

**Actual LLM response.** The saved pass/fail counts are 8/10, 80/100, and 800/1,000.

**Assessment.** Each numerator divided by its denominator is 0.80. For 8/10 the Wilson center is about 0.717 and the half-width about 0.227. For 80/100 they are about 0.789 and 0.078. For 800/1,000 they are about 0.799 and 0.025. Using the unrounded values, the 95% intervals are 49.02–94.33%, 71.12–86.66%, and 77.41–82.36%.

**Failure classification.** The widths shrink from 45.32 to 15.55 to 4.95 percentage points. Repeating a cached reply 1,000 times would not supply the distinct cases needed for the third claim. Check the case mix as well as the count.

### Example 2. Count gains and losses on the same questions

**User question.** Do the first 20 paired cases support a difference between A and B?

**Approved reference.** Each configuration faces the same cases and the same binary refund rubric. The exact paired test uses a two-sided 0.05 threshold fixed in advance.

**Actual LLM response.** Both pass on C01–C14, A alone passes on C15–C16, B alone passes on C17–C19, and both fail on C20. All labels are illustrative.

**Assessment.** A passes 14 + 2 = 16/20. B passes 14 + 3 = 17/20. The observed gain is (3 − 2)/20 = 5 percentage points. Use only the five discordant directions for the exact test. The smaller tail through two has 16 of the 32 null sequences, and doubling it yields p = 1.00000.

**Failure classification.** The evidence is inconclusive about an underlying difference. It also cannot establish equivalence. Collect more matched cases and check whether the expected benefit and policy risk warrant a larger study.

### Example 3. A supported gain still hits a critical gate

**User question.** Can Harbor Leaf release B after the larger paired evaluation?

**Approved reference.** The lab’s fictional release plan requires at least 99% matched coverage, a positive gain of at least 3 percentage points, exact p ≤ 0.05, and completed critical review with zero verified critical failures for B.

**Actual LLM response.** Of 202 planned cases, two have one invalid verdict, leaving 200 complete pairs. Both pass on 156, A alone on 4, B alone on 14, and neither on 26. B’s captured C157 reply wrongly promises 90 days.

**Assessment.** A passes (156 + 4)/200 = 80%. B passes (156 + 14)/200 = 85%. Their marginal Wilson intervals are 73.91–84.95% and 79.39–89.29%. The paired effect is (14 − 4)/200 = +5 points. The null gives 2¹⁸ equally likely discordant direction sequences. The tail through four has 1 + 18 + 153 + 816 + 3060 = 4048. Doubling and dividing by 262,144 gives p ≈ 0.03088. Coverage is 200/202 = 99.01%.

**Failure classification.** Write HOLD on the release sheet and attach reply C157. At day 45, the 90-day reply says to go ahead, even though the store’s window closed on day 30. The paired test and the observed gain clear their respective rules, so keep those results too. The team needs both records to understand why a promising gain still leaves a customer-facing error to fix.

### Step 2 — Calculate the Wilson interval

Use 8 of 10 and compute the divisor, center, and half-width from the worked numbers. `** 2` squares a value, `sqrt()` takes the square root, and `return` sends the two limits back together. The two names before `=` receive the lower and upper limits in that order.

[Open Python Editor](https://www.online-python.com/)

```python
from math import sqrt

def wilson(passes, n, z):
    p = passes / n
    z2 = z ** 2
    divisor = 1 + z2 / n
    center = (p + z2 / (2 * n)) / divisor
    half = z * sqrt(p * (1 - p) / n + z2 / (4 * n ** 2)) / divisor
    return center - half, center + half

passes, n = 8, 10
low, high = wilson(passes, n, 1.959963984540054)
print(f"Observed: {passes}/{n} ({passes / n:.2%})")
print(f"Wilson 95%: {low:.2%} to {high:.2%}")
print(f"Width: {100 * (high - low):.2f} pp")
```

```text
Observed: 8/10 (80.00%)
Wilson 95%: 49.02% to 94.33%
Width: 45.32 pp
```

**Experiment.** Change the whole count pair to `passes, n = 80, 100`. Keep 80% fixed and predict the width.

### Step 5 — Test the discordant directions

Use the twenty-case demonstration. Keep the number of pairs, A-only passes, and both-fail cases fixed. Changing B-only replaces some both-pass rows, leaving B’s number of passes fixed. `comb(m, k)` counts the ways to choose `k` of `m` positions for one direction. The loop adds the counts through the smaller observed direction. There are `2 ** m` possible sequences.

[Open Python Editor](https://www.online-python.com/)

```python
from math import comb

def exact_p(a_only, b_only):
    m = a_only + b_only
    if m == 0:
        return 1.0
    tail = sum(comb(m, k) for k in range(min(a_only, b_only) + 1))
    return min(1.0, 2 * tail / (2 ** m))

n = 20
a_only, b_only, neither = 2, 3, 1
both = n - a_only - b_only - neither
assert both >= 0
p_value = exact_p(a_only, b_only)
print(f"Both pass {both} | A only {a_only} | B only {b_only} | both fail {neither}")
print(f"Discordant: {a_only + b_only} | effect {100 * (b_only - a_only) / n:+.1f} pp")
print(f"Exact two-sided p: {p_value:.5f}")
print("Reject equality at 0.05" if p_value <= 0.05 else "Do not reject equality at 0.05")
```

### Step 6 — Plan for a target interval width

Assume a fixed observed rate of 80%. Try planning sizes in steps of ten so that four fifths gives a whole pass count. [Open Python Editor](https://www.online-python.com/)

```python
from math import sqrt

def width(n):
    p = (4 * n // 5) / n
    z = 1.959963984540054
    z2 = z * z
    half = z * sqrt(p * (1 - p) / n + z2 / (4 * n * n)) / (1 + z2 / n)
    return 2 * half

for n in (10, 100, 1000):
    print(f"n={n}: width {100 * width(n):.2f} pp")

target = 0.10
chosen = next((n for n in range(10, 2001, 10) if width(n) <= target), None)
```

### Step 7 — Reproduce a release report

Use the twenty scored pairs from the small demonstration and one planned case with an invalid B verdict. The rows contain saved values, not live model calls. `dict.get()` can look up an adjudication for one case and retain its original status otherwise. `all()` tests whether both labels belong to the binary scale. Both A-only pairs enter the statistical table because both binary labels are valid. Their separate critical review can still be pending.

[Open Python Editor](https://www.online-python.com/)

```python
from math import comb, sqrt

dataset, rubric = "refund-small-1", "refund-binary-v1"
config_a, config_b = "A/current", "B/proposed"
revision = "baseline"
z = 1.959963984540054
raw = {}
for i in range(1, 22):
    a = "PASS" if i <= 16 or i == 21 else "FAIL"
    b = "PASS" if i <= 14 or 17 <= i <= 19 else "FAIL"
    raw[f"C{i:02d}"] = (a, "INVALID" if i == 21 else b, "PENDING" if i == 15 else "CLEAR")
adjudications = {"baseline": {}, "confirmed": {"C15": "FAIL"}}

def wilson(k, n):
    p = k / n
    z2 = z * z
    d = 1 + z2 / n
    center = (p + z2 / (2 * n)) / d
    half = z * sqrt(p * (1 - p) / n + z2 / (4 * n * n)) / d
    return center - half, center + half

audit = {case: (a, b, original, adjudications[revision].get(case, original))
         for case, (a, b, original) in raw.items()}
paired = [row for row in audit.values() if all(label in ("PASS", "FAIL") for label in row[:2])]
n = len(paired)
a_pass = sum(row[0] == "PASS" for row in paired)
b_pass = sum(row[1] == "PASS" for row in paired)
a_only = sum(row[:2] == ("PASS", "FAIL") for row in paired)
b_only = sum(row[:2] == ("FAIL", "PASS") for row in paired)
m = a_only + b_only
p = min(1.0, 2 * sum(comb(m, k) for k in range(min(a_only, b_only) + 1)) / (2 ** m))
effect = (b_pass - a_pass) / n
critical = [case for case, row in audit.items() if row[3] == "FAIL"]
pending = [case for case, row in audit.items() if row[3] == "PENDING"]
excluded = [case for case, row in audit.items() if not all(label in ("PASS", "FAIL") for label in row[:2])]
if critical:
    decision = "HOLD"
elif pending or n / len(raw) < 0.99 or p > 0.05 or effect < 0.03:
    decision = "REVIEW"
else:
    decision = "RELEASE"

print(f"{dataset} | {rubric} | {config_a} vs {config_b} | {revision}")
print(f"Paired coverage: {n}/{len(raw)} | excluded: {', '.join(excluded)}")
for name, count in [("A", a_pass), ("B", b_pass)]:
    low, high = wilson(count, n)
    print(f"{name}: {count} pass, {n-count} fail | {count/n:.1%} | Wilson 95% {low:.2%} to {high:.2%}")
print(f"Effect B-A: {effect*100:+.1f} pp | A only {a_only} | B only {b_only} | exact p {p:.5f}")
print("Statistical threshold: " + ("met" if p <= 0.05 else "not met"))
print("Observed practical floor (+3 pp): " + ("met" if effect >= 0.03 else "not met"))
print(f"B critical: {', '.join(critical) or 'none'} | B pending: {', '.join(pending) or 'none'}")
print(f"Audit C15: original gate {raw['C15'][2]} | replay gate {audit['C15'][3]}")
print(f"Recommendation: {decision}")
```

```text
refund-small-1 | refund-binary-v1 | A/current vs B/proposed | baseline
Paired coverage: 20/21 | excluded: C21
```

## Knowledge Check

1. A report has 800 passes out of 1,000 rows, but only ten distinct customers were repeatedly rated. What should you ask about sample size?
2. What could happen if a new representative sample is evaluated with the same fixed configurations?
3. Does a computed 95% interval assign a 95% probability to the fixed underlying rate being inside those endpoints?
4. When the data stay fixed, why is a 99% Wilson interval wider than a 90% one?
5. A paired test reports p = 0.40. What can you infer about equality?
6. In the paired bootstrap, what must stay together and why?
7. A gain of one point is statistically detectable but adds substantial review work. What additional judgment should the team make?
8. Five candidates were tried on the same holdout. The chosen one looks safest and has the smallest p-value. What would you do before relying on that result?

## Knowledge Check Answers

1. Ask which independent units were sampled. Repeated ratings of the same customer or cases do not create 1,000 independent units. Keep related cases together in the analysis.
2. The case mix and outcomes could differ, producing another observed rate and interval. Check that the collection and rubric stay comparable.
3. No. The confidence level describes a repeated-sampling procedure under assumptions. The fixed rate is either inside or outside this realized interval.
4. The larger cutoff reaches farther into the reference curve. The procedure uses a wider span to aim for greater coverage with the same data.
5. The test did not reject equality at 0.05. It may have little information, so report the observed effect, sample size and uncertainty. Equality or practical equivalence needs its own evidence.
6. Keep both answers or labels for a case in one draw. The pairing preserves how the two outcomes relate on easy and difficult cases.
7. Compare the size and type of errors prevented with cost, review time, and the separate critical requirements. Statistical detectability does not settle the trade-off.
8. Record all attempts, select a primary configuration and criterion in advance for a new holdout, and keep the independent policy checks. Selecting the best on the old holdout can inflate apparent evidence.

### Run the saved report

The replay program builds one record per case. A dictionary comprehension uses the case ID as the key, and `assert` checks for duplicate IDs and incomplete coverage of the planned ID set. The whole-pair bootstrap draws a case index and uses that case’s B-minus-A change. A seeded `Random` gives a reproducible stream. Multiplying a value in [0, 1) by `n` and taking `int()` selects an index from 0 to `n − 1`. Repeat `n` selections per draw. Sort 4,000 differences and take the nearest ranks at 2.5% and 97.5%. `ceil(fraction * draws) − 1` converts an upward-rounded rank to a zero-based index.

For contrast only, the report also computes an approximate interval **as if** the samples were independent. The estimated variance of a single binary sample proportion is `p(1−p)/n` under this approximation. Independent variances add. For 80% and 85% with 200 each, the square root of `(0.80 × 0.20 + 0.85 × 0.15)/200` is about 0.0379. Multiply by 1.96 to get a half-width of about 7.43 points. This independent-design interval is not valid as the paired result. Both answers on each actual case share its difficulty.

```python
def wilson(k, n):
    p = k / n
    z2 = z * z
    divisor = 1 + z2 / n
    center = (p + z2 / (2 * n)) / divisor
    half = z * sqrt(p * (1 - p) / n + z2 / (4 * n * n)) / divisor
    return center - half, center + half

def exact_p(a_only, b_only):
    m = a_only + b_only
    return min(1.0, 2 * sum(comb(m, k) for k in range(min(a_only, b_only) + 1)) / (2 ** m))

def paired_interval(changes):
    rng = Random(seed)
    n = len(changes)
    effects = sorted(sum(changes[int(rng.random() * n)] for _ in range(n)) / n
                     for _ in range(draws))
    return effects[ceil(0.025 * draws) - 1], effects[ceil(0.975 * draws) - 1]

planned = len(audit)
pairs = [r["labels"] for r in audit.values() if all(label in labels for label in r["labels"])]

valid_b = sum(r["labels"][1] in labels for r in audit.values())

b_only = pairs.count(("FAIL", "PASS"))

print(f"Independent-design contrast only: {100*(effect-z*independent_se):+.2f} to {100*(effect+z*independent_se):+.2f} pp")
print(f"Rules: observed floor {100*minimum_gain:.0f} pp | coverage {coverage_floor:.0%} | alpha {alpha:.2f}")
```

## Common Mistakes

Read the denominators before comparing rates. A different or invalid row can change the result even when the remaining answers stay fixed.

Use whole paired case records for uncertainty in a matched design. Judge replays on the same examples can diagnose scoring variation and still leave the number of independent cases unchanged.

Report the effect, method, coverage, and policy evidence together. A missed threshold leaves an open decision. A verified critical violation can settle it.
