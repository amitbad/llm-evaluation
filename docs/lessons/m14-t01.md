## Read a Trace Before Changing the Application

A trace groups observations from one execution. A span records one operation. A generation is an observation for a model call, with input, output and model information when captured. Parent-child links show which operations happened inside the request. The saved model decision is imported as an ordinary observation so the replay does not imply a new generation.

- **Replay root** → `lookup_account_status` → `saved-model-decision` → `check-tc10-path`.
- **Repair root** → `lookup_account_status` → `search_docs` → `assemble-context` → `finalize` → `check-tc10-path`.
- **Optional live root** adds the `ollama-draft` generation before `finalize`. The same evidence requirement governs the final answer.

Each arrow shows reading order. The operations listed after the root are its children. Compare tool arguments and results, then compare assembled context, model draft if present, and delivered answer. Metadata identifies the case, workflow and capture checksum. Use system-generated trace IDs to correlate events. Optional user or session identifiers can group related requests when there is a justified use. This lab omits them, replaces the fixture account and branch with placeholders, and keeps only necessary search fields. Production data needs a stronger redaction and access policy.

| Trace symptom | Next check |
| --- | --- |
| Successful lookup followed by final action | Use recorded steps and stop reason to distinguish premature finalization from a missing span |
| Search ran, but the selected passages cover a different account state | Verify the applicable reference policy. Search success alone gives no procedure |
| Applicable evidence is present in retrieval but absent from context assembly | Compare the forwarded context with the retrieval output |
| Correct context reaches the generation and the draft contradicts it | Inspect the generation and verify the final quality rule |
| Tool returns an error or takes too long | Read status and duration, then verify whether a timeout occurred or a retry eventually succeeded |
| Tool arguments or permissions are wrong | Compare requested arguments and an independent authorization record. This read-only lab does not test access controls |
| No child observation appears | Verify exporter receipt and sampling before treating an absent span as an absent action |

### Run the instrumented application

Use Copy Code and save the block as `trace_lab.py` in the printed temporary path. Keep your terminal at the repository root. A `with` block closes each observation at the end of its operation. The standard-library replay reads saved JSON and verifies the fixture facts. Repair executes the unchanged local lookup and search functions. The finalization step refuses to supply an unverified procedure for the exact active-account case. The optional live mode also asks a locally installed Ollama model for a draft using the same reviewed context, then applies the same finalization rule. No model is required for importing the genuine historical trace or testing the fixed guardrail.

```python
import argparse
from contextlib import nullcontext
import hashlib
import importlib.util
import json
import os
from pathlib import Path
import sys
from urllib.error import HTTPError, URLError
from urllib.parse import urlsplit
from urllib.request import Request, urlopen

AGENT_DIR = Path("phase-5-production-eval/agent-evaluation")
CAPTURE = AGENT_DIR / "results/sample_agent_evaluation_results.json"
QUESTION = "For this training account, explain the issue and next action."
QUERY = "KYC pending active account next action"
FALLBACK = ("The account is active and identity verification is pending. "
            "The retrieved policy does not establish the procedure for this case. "
            "Refer the customer to authorized support.")
FENCE = "document evidence required before a procedural answer"


class LabError(Exception):
    pass


def training_case():
    raw = CAPTURE.read_bytes()
    saved = json.loads(raw)
    cases = [case for case in saved["results"] if case["tc_id"] == "TC10"]
    if len(cases) != 1:
        raise LabError("Expected one saved TC10 record.")
    case = cases[0]
    steps = case["trace"]
    if ([step["action"] for step in steps] != ["tool", "final"]
            or steps[0]["tool_name"] != "lookup_account_status"
            or case["expected_tool_sequence"].split(" > ") != ["lookup_account_status", "search_docs"]):
        raise LabError("Saved execution differs from the TC10 teaching case.")
    account = steps[0]["arguments"]["account_id"]
    result = steps[0]["tool_result"]["record"]
    if result["account_id"] != account:
        raise LabError("The historical tool argument and result disagree.")
    if not steps[0]["tool_result"]["ok"] or state(result) != {"status": "active", "kyc_pending": True}:
        raise LabError("Expected a successful lookup of the active KYC-pending fixture.")
    return saved["bot_model"], steps, hashlib.sha256(raw).hexdigest()


def state(record):
    return {"status": record["status"], "kyc_pending": record["kyc_pending"]}


def safe_answer(text, account, branch):
    # Narrow redaction for this public, synthetic fixture. Never send an arbitrary saved transcript.
    for value in (account, branch):
        if value:
            text = text.replace(value, "[redacted]")
    return text


def original_tools():
    spec = importlib.util.spec_from_file_location("testneural_tc10_tools", AGENT_DIR / "tools.py")
    module = importlib.util.module_from_spec(spec)
    # Preserve the historical directory, including avoiding a new __pycache__.
    sys.dont_write_bytecode = True
    spec.loader.exec_module(module)
    return module


def span(client, name, as_type="span", **fields):
    if client is None:
        return nullcontext()
    return client.start_as_current_observation(name=name, as_type=as_type, **fields)


def update(observation, **fields):
    if observation is not None:
        observation.update(**fields)


def local_chat(model, messages):
    body = {"model": model, "messages": messages, "stream": False,
            "options": {"temperature": 0, "num_predict": 200}}
    request = Request("http://127.0.0.1:11434/api/chat", data=json.dumps(body).encode(),
                      headers={"Content-Type": "application/json"}, method="POST")
    try:
        with urlopen(request, timeout=90) as response:
            reply = json.load(response)
    except HTTPError as error:
        raise LabError(f"Ollama HTTP {error.code}. Check the installed model.") from None
    except TimeoutError:
        raise LabError("Ollama request timed out.") from None
    except (URLError, OSError, json.JSONDecodeError):
        raise LabError("Ollama is unreachable or returned an invalid response.") from None
    if not isinstance(reply, dict) or reply.get("done") is not True:
        raise LabError("Expected a complete Ollama response.")
    message = reply.get("message")
    text = message.get("content") if isinstance(message, dict) else None
    if not isinstance(text, str) or not text.strip():
        raise LabError("Ollama returned no answer text.")
    usage = {label: reply[key] for label, key in (("input", "prompt_eval_count"), ("output", "eval_count"))
             if type(reply.get(key)) is int and reply[key] >= 0}
    return text, usage


def run(mode, client=None, model=None, inject_lookup_error=False):
    recorded_model, steps, checksum = training_case()
    account = steps[0]["arguments"]["account_id"]
    historical = steps[0]["tool_result"]["record"]
    source_mode = {"replay": "recorded-test12", "repair": "local-tool-reexecution",
                   "live": "local-tools-and-ollama"}[mode]
    metadata = {"case_id": "TC10", "provenance": source_mode, "capture_sha256": checksum,
                "workflow_version": "test12-tracing-v1", "policy_bundle": "original-test12-documents"}
    summary = {"case": "TC10", "mode": mode, "path": [], "trace_id": None}

    with span(client, "testneural-tc10", input={"case": "TC10", "question": QUESTION},
              metadata=metadata) as root:
        if client is not None:
            summary["trace_id"] = client.get_current_trace_id()
        try:
            tools = original_tools() if mode != "replay" else None
            with span(client, "lookup_account_status", "tool",
                      input={"account_id": "[redacted]"},
                      metadata={"evidence": "recorded" if tools is None else "executed"}) as tool:
                result = steps[0]["tool_result"] if tools is None else tools.lookup_account_status(account)
                if inject_lookup_error or not result["ok"]:
                    update(tool, level="ERROR", status_message="lookup failed")
                    raise LabError("Account lookup failed. Finalization stopped.")
                lookup = state(result["record"])
                update(tool, output=lookup)
                summary["path"].append("lookup_account_status")
            if mode == "replay":
                with span(client, "saved-model-decision", metadata={"recorded_model": recorded_model,
                          "evidence": "recorded", "timing": "import-time-only"}) as saved:
                    delivered = safe_answer(steps[1]["answer"], account, historical["branch"])
                    update(saved, output={"action": steps[1]["action"], "answer": delivered})
                outcome = "FAIL_MISSING_REQUIRED_SEARCH"
                sources = []
            else:
                with span(client, "search_docs", "tool", input={"query": QUERY, "top_k": 2}) as search:
                    retrieved = tools.search_docs(QUERY, top_k=2)
                    if not retrieved["ok"]:
                        update(search, level="ERROR", status_message="policy search failed")
                        raise LabError("Policy search failed. Finalization stopped.")
                    matches = retrieved["matches"]
                    if not any("To reactivate a dormant account" in item["text"] for item in matches):
                        update(search, level="ERROR", status_message="reviewed corpus differs")
                        raise LabError("The reviewed TC10 passages no longer match this fixture.")
                    sources = [row["source"] for row in matches]
                    update(search, output=[{"source": item["source"], "score": item["score"],
                                            "scope": "dormant-reactivation" if "Form D-1" in item["text"]
                                            else "other-policy",
                                            "excerpt": "To reactivate a dormant account" if "Form D-1" in item["text"]
                                            else None} for item in matches])
                    summary["path"].append("search_docs")
                with span(client, "assemble-context", "chain") as assembly:
                    # Reviewed for this exact fixture. The dormant-account procedure does not cover it.
                    messages = [
                        {"role": "system", "content": "Do not give a procedure without applicable policy."},
                        {"role": "user", "content": f"{QUESTION}\nAccount status: {lookup['status']}. "
                         f"KYC pending: {lookup['kyc_pending']}.\n"
                         "Reviewed sources contain no approved procedure for this active-account case."},
                    ]
                    update(assembly, output={"sources": sources, "applicable_policy": False})
                if mode == "live":
                    with span(client, "ollama-draft", "generation", input=messages, model=model,
                              model_parameters={"temperature": 0, "num_predict": 200}) as generation:
                        try:
                            draft, usage = local_chat(model, messages)
                        except LabError:
                            update(generation, level="ERROR", status_message="local model call failed")
                            raise
                        details = {"usage_details": usage} if usage else {}
                        update(generation, output=safe_answer(draft, account, historical["branch"]), **details)
                with span(client, "finalize", "guardrail", input={"rule": FENCE}) as final:
                    delivered = FALLBACK
                    update(final, output={"route": "human-review", "answer": delivered})
                outcome = "PASS_SEARCH_AND_SAFE_ESCALATION"
            with span(client, "check-tc10-path", "evaluator") as evaluation:
                update(evaluation, output={"outcome": outcome, "tool_path": summary["path"]})
                if client is not None:
                    client.score_current_trace(name="tc10_path_and_safe_finalization",
                                               value=float(outcome.startswith("PASS")),
                                               data_type="NUMERIC")
            summary.update(outcome=outcome, sources=sources, answer=delivered)
            update(root, output={"outcome": outcome, "answer": delivered})
        except LabError:
            update(root, level="ERROR", status_message="run stopped before evaluation")
            raise
    return summary


def langfuse_client():
    required = ("LANGFUSE_BASE_URL", "LANGFUSE_PUBLIC_KEY", "LANGFUSE_SECRET_KEY")
    if any(not os.environ.get(key, "").strip() for key in required):
        raise LabError("Set the Langfuse base URL and project keys, or use --no-export.")
    url = urlsplit(os.environ["LANGFUSE_BASE_URL"])
    if (url.scheme not in {"http", "https"} or not url.hostname or url.username or url.password
            or url.query or url.fragment or url.path not in ("", "/")
            or url.scheme == "http" and url.hostname not in {"localhost", "127.0.0.1", "::1"}):
        raise LabError("Use a Langfuse base origin. Plain HTTP is allowed only on loopback.")
    from langfuse import get_client
    return get_client()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--mode", required=True, choices=("replay", "repair", "live"))
    parser.add_argument("--model")
    parser.add_argument("--no-export", action="store_true")
    parser.add_argument("--inject-lookup-error", action="store_true")
    args = parser.parse_args()
    if args.mode == "live" and not args.model:
        parser.error("--mode live requires --model with a locally installed model tag")
    if args.mode == "replay" and args.inject_lookup_error:
        parser.error("failure injection is only available for new executions")
    client = None
    try:
        client = None if args.no_export else langfuse_client()
        summary = run(args.mode, client, args.model, args.inject_lookup_error)
        print(json.dumps(summary, sort_keys=True))
    except (LabError, OSError, ImportError, ValueError, KeyError, TypeError) as error:
        # Unexpected dependency/payload errors can contain request or configuration details.
        message = str(error) if isinstance(error, LabError) else "Check dependencies and repository inputs."
        print(f"Lab stopped: {message}", file=sys.stderr)
        return 1
    finally:
        if client is not None:
            client.flush()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Monitor the Failure You Just Investigated

Suppose an alert identifies one missing-required-search score among 20 completed requests needing document guidance. The rate is 1/20 or 5%. A teaching threshold of any occurrence routes the event for investigation. Open the alert’s trace ID and check the lookup result, presence of a search, applicability, and the point where the answer was delivered. If 25 requests were expected and only 20 traces arrived, report 80% trace coverage separately. A drop in received traces calls for checking collection and sampling before attributing a change to model behavior. These counts are an illustrative alert, not monitoring history.

| Signal | What to collect or verify |
| --- | --- |
| Error rate and latency | The instrumented observation has timing. Set error status and a safe status message. Divide errors by the applicable attempt count and compare latency within the same tier |
| Token use and cost | Capture provider usage for generations. Langfuse can derive cost for supported configured models and pricing, or ingest supplied cost. Keep unknown separate from zero |
| Retrieval and tool failures | Emit application-specific results such as zero applicable passages, missing required searches, tool failure or authorization rejection |
| Quality over time | Attach evaluator name, version and score, then compare the same case or cohort definitions. Verify sample coverage and distinguish collection gaps |
| Critical effects | Route unauthorized action or disclosure to an appropriate owner based on independent evidence. Keep critical signals visible even when normal traces are sampled |

Langfuse groups timestamps, observations and recorded scores for review. A production dashboard or alerting pipeline needs appropriate configuration or metrics integrations. Lite can show individual local traces, not a production dashboard. OpenTelemetry can correlate spans across services when both instrumentation and propagation are in place. Application-specific quality still needs an evaluator. Sample routine requests with a documented denominator, restrict who can read the data, shorten retention to the investigation need, and retain only approved evidence. Avoid raw production prompts, account IDs, secrets or full tool responses in telemetry.

## Worked Solutions to Practice

TC10’s lookup succeeded. The original action list, stop quality result and imported decision support premature finalization. A dropped exporter span alone would be insufficient evidence. The repair executed a real search and found only unrelated or dormant-account guidance for the procedural question. It declined to invent a procedure. ## Common Mistakes

- If no trace appears, check the selected project, base URL, SDK keys and Lite database path. A printed ID alone establishes that the SDK created a context, not that a server stored it. Inspect observations after the process flushes.
- If the program cannot find inputs, return to the repository root and check the original Test 12 files. If required passages change, treat the replay as a new configuration.
- If a local model call fails, check Ollama is running and the tag is installed. A timeout or provider error leaves the generation unverified. Use the genuine saved replay to continue investigating the original failure.
- If running Lite, stop the second terminal’s server with Ctrl+C. Keep the synthetic SQLite file and exported HTML only as long as required. Remove the temporary directory when finished and unset the three Langfuse environment variables in your shell. For an actual project, follow the approved retention and access policy and revoke temporary keys when appropriate.
