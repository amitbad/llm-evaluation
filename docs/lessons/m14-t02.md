The read-only workbook loader finds the sheet header and uses `zip` to pair field names with cells. `Random(seed)` samples without replacement, and `Counter` counts categories. A dictionary holds each window’s counts. The alert state remembers consecutive qualifying windows, whether an alert is still open and the number of clean recovery windows. `--audit` writes a new JSON record and refuses to overwrite an existing one.

import argparse
from collections import Counter, defaultdict
import hashlib
import json
import os
from pathlib import Path
from random import Random
from urllib.parse import urlsplit

from openpyxl import load_workbook

WORKBOOK = Path("phase-2-evaluation-techniques/llm-as-a-judge/banking_bot_test_results.xlsx")
LABELS = {"PASS", "PARTIAL", "FAIL"}
RISK_TAG = "Prompt Injection"  # Review priority, not a verified critical incident.
SEED = 14
BASE_VERSION = ("fixture-model-v1", "fixture-prompt-v1", "fixture-judge-v1", "fixture-policy-v1")
SLICES = ("routine", "policy")
# name, routine (planned, passed), policy (planned, passed), missing policy labels, verified critical
WINDOWS = [
    ("baseline", (80, 72), (20, 10), 0, False),
    ("mix", (20, 18), (80, 40), 0, False),
    ("drop-1", (20, 18), (80, 24), 0, False),
    ("gap", (20, 18), (80, 24), 65, False),
    ("drop-2", (20, 18), (80, 24), 0, False),
    ("drop-3", (20, 18), (80, 24), 0, False),
    ("critical", (1, 1), (1, 0), 1, True),
    ("recovery-1", (20, 18), (80, 40), 0, False),
    ("recovery-2", (20, 18), (80, 40), 0, False),
]
# Simulated review events. Availability is a sequence marker, not a historical timestamp.
FEEDBACK = [
    {"event": "F01", "request": "drop-3:policy:000", "reviewer": "qa-01", "available": 6,
     "status": "final", "label": "FAIL", "issue": "missing_context"},
    {"event": "F02", "request": "drop-3:policy:001", "reviewer": "qa-02", "available": 8,
     "status": "final", "label": "FAIL", "issue": "missing_context"},
    {"event": "F03", "request": "mix:routine:000", "reviewer": "qa-01", "available": 2,
     "status": "final", "label": "PASS", "issue": "none"},
    {"event": "F04", "request": "drop-3:policy:002", "reviewer": "qa-03", "available": 6,
     "status": "pending", "label": None, "issue": "needs_adjudication"},
]
POLICY = {"min_policy_scored": 20, "min_coverage": 0.8, "drop_pp": 15,
          "consecutive": 2, "recovery_ratio": 0.95, "recovery_windows": 2}


def deduplicate(rows, key):
    unique = {}
    for row in rows:
        identity = row[key]
        if identity in unique and unique[identity] != row:
            raise ValueError(f"Conflicting duplicate {identity}")
        unique[identity] = row
    return list(unique.values())


def historical(path):
    workbook = load_workbook(path, read_only=True, data_only=True)
    required = {"ID", "Test Type", "Hallucination Type", "Bot Response",
                "Expected Behaviour", "Your Verdict (normalised)", "Judge Verdict"}
    try:
        rows = iter(workbook["JudgeResults"].values)
        stamp = next(rows)[0]
        for row in rows:
            if row and row[0] == "ID":
                break
        else:
            raise ValueError("JudgeResults header missing")
        if not required <= set(row):
            raise ValueError("JudgeResults columns changed")
        records = []
        for cells in rows:
            if cells[0] is None:
                continue
            item = dict(zip(row, cells))
            human, judge = item["Your Verdict (normalised)"], item["Judge Verdict"]
            if human is not None and human not in LABELS or judge is not None and judge not in LABELS:
                raise ValueError("Unrecognized verdict")
            records.append({"id": int(item["ID"]), "category": item["Test Type"],
                            "issue": item["Hallucination Type"], "human": human, "judge": judge,
                            "has_reply": bool(item["Bot Response"])})
    finally:
        workbook.close()
    return sorted(deduplicate(records, "id"), key=lambda row: row["id"]), stamp


def samples(rows, size, seed):
    groups = defaultdict(list)
    for row in rows:
        groups[row["category"]].append(row)
    categories = sorted(groups)
    if RISK_TAG not in groups or not len(groups[RISK_TAG]) <= size <= len(rows):
        raise ValueError("Sample size cannot cover the declared risk stratum")
    quota, extra = divmod(size, len(categories))
    rng = Random(seed)
    simple = rng.sample(rows, size)
    rng = Random(seed)
    strata = [row for i, name in enumerate(categories)
              for row in rng.sample(groups[name], quota + int(i < extra))]
    risk = groups[RISK_TAG]
    others = [row for row in rows if row["category"] != RISK_TAG]
    targeted = risk + Random(seed).sample(others, size - len(risk))
    return {"random": simple, "stratified": strata, "risk": targeted}


def paired(rows):
    return [row for row in rows if row["human"] in LABELS and row["judge"] in LABELS]


def pct(numerator, denominator):
    return "n/a" if denominator == 0 else f"{numerator / denominator:.1%}"


def counts(counter):
    return ", ".join(f"{key}={counter[key]}" for key in sorted(counter))


def historical_report(rows, stamp, path):
    if not rows:
        raise ValueError("Empty workbook population")
    population = Counter(row["category"] for row in rows)
    print(f"Workbook SHA-256: {hashlib.sha256(path.read_bytes()).hexdigest()}")
    print(f"Workbook batch: {stamp}; request timestamps/trace IDs: absent")
    print(f"Population {len(rows)}: {counts(population)}; responses={sum(r['has_reply'] for r in rows)}")
    chosen = samples(rows, 20, SEED)
    assert chosen == samples(rows, 20, SEED), "Sampling changed for an identical seed"
    for name, selected in chosen.items():
        distribution = Counter(row["category"] for row in selected)
        print(f"{name}: {len(selected)}/{len(rows)}; categories {len(distribution)}/{len(population)}; "
              f"risk tags {distribution[RISK_TAG]}/{population[RISK_TAG]}; {counts(distribution)}")
    by_category = defaultdict(list)
    for row in chosen["stratified"]:
        by_category[row["category"]].append(row)
    if all(rows and len(paired(rows)) == len(rows) for rows in by_category.values()):
        weighted = sum(population[name] / len(rows) *
                       sum(row["human"] == "PASS" for row in sample) / len(sample)
                       for name, sample in by_category.items())
        print(f"Stratified human PASS: raw {pct(sum(r['human'] == 'PASS' for r in chosen['stratified']), 20)}; "
              f"population-weighted estimate {weighted:.1%}")
    cases = paired(rows)
    disagreements = [r for r in cases if r["human"] != r["judge"]]
    agreements = len(cases) - len(disagreements)
    print(f"Saved agreement: {agreements}/{len(cases)} ({pct(agreements, len(cases))}); "
          f"disagreement: {len(disagreements)}; unpaired: {len(rows)-len(cases)}")
    print("Disagreements by category:", counts(Counter(r["category"] for r in disagreements)))
    print("Disagreements by recorded issue:", counts(Counter(r["issue"] for r in disagreements)))
    print("Judge PASS / human FAIL:", ", ".join(str(r["id"]) for r in disagreements
                                                   if r["judge"] == "PASS" and r["human"] == "FAIL"))


def window_records(name, routine, policy, missing, critical):
    rows = []
    for category, (size, passes) in zip(SLICES, (routine, policy), strict=True):
        for i in range(size):
            # Rank low IDs as failures to reserve stable review examples.
            passed = i >= size - passes
            available = category != "policy" or i < size - missing
            incident = critical and category == "policy" and i == 0
            rows.append({"id": f"{name}:{category}:{i:03d}", "window": name, "category": category,
                         "version": BASE_VERSION, "synthetic": True,
                         "quality": passed if available else None,
                         "signal": "missing_context" if not passed and category == "policy" else None,
                         "receipt": "verified-unauthorized-write" if incident else None})
    return rows


def summarize(window, records):
    if any(row["window"] != window or row["category"] not in SLICES or
           row["quality"] is not None and type(row["quality"]) is not bool for row in records):
        raise ValueError("Invalid monitoring row")
    rows = deduplicate(records, "id")
    groups = {}
    for category in SLICES:
        subset = [row for row in rows if row["category"] == category]
        scored = [row for row in subset if row["quality"] is not None]
        groups[category] = {"total": len(subset), "scored": len(scored),
                            "passed": sum(row["quality"] for row in scored)}
    totals = {key: sum(group[key] for group in groups.values()) for key in ("total", "scored", "passed")}
    return {**totals, "groups": groups,
            "versions": {row["version"] for row in rows},
            "critical": [row["id"] for row in rows if row["receipt"] == "verified-unauthorized-write"]}


def standardized(baseline, current):
    if baseline["versions"] != current["versions"] or len(current["versions"]) != 1:
        return None
    if any(group["scored"] != group["total"] or not group["scored"]
           for summary in (baseline, current) for group in summary["groups"].values()):
        return None
    return sum(baseline["groups"][category]["total"] / baseline["total"] *
               group["passed"] / group["scored"] for category, group in current["groups"].items())


def available_feedback(cutoff, events):
    selected = [row for row in deduplicate(events, "event") if row["available"] <= cutoff]
    return [row for row in selected if row["status"] == "final" and row["label"] in LABELS], len(selected)


def alert_step(baseline, current, state, resolved=False):
    # A corroborated side effect is assessed before ordinary coverage or thresholds.
    if current["critical"]:
        state.update(open="critical", streak=0, recovered=0)
        return "CRITICAL / ESCALATE"
    group = current["groups"]["policy"]
    baseline_group = baseline["groups"]["policy"]
    comparable = current["versions"] == baseline["versions"] and len(current["versions"]) == 1
    if (not comparable or not current["total"] or current["scored"] / current["total"] < POLICY["min_coverage"]
            or group["scored"] < POLICY["min_policy_scored"]
            or group["scored"] != group["total"] or not baseline_group["scored"]):
        state.update(streak=0, recovered=0)
        return "INSUFFICIENT / COLLECT MORE EVIDENCE"
    rate = group["passed"] / group["scored"]
    reference = baseline_group["passed"] / baseline_group["scored"]
    if (reference - rate) * 100 >= POLICY["drop_pp"]:
        state["streak"] += 1
        state["recovered"] = 0
        if state["open"] == "critical":
            return "CRITICAL OPEN / ESCALATE"
        if state["streak"] >= POLICY["consecutive"]:
            state["open"] = "warning"
            return "WARNING / MITIGATE"
        return "WATCH / INVESTIGATE"
    state["streak"] = 0
    if state["open"]:
        if rate < reference * POLICY["recovery_ratio"] or (state["open"] == "critical" and not resolved):
            state["recovered"] = 0
            return "OPEN / INVESTIGATE"
        state["recovered"] += 1
        if state["recovered"] >= POLICY["recovery_windows"]:
            state.update(open=None, recovered=0)
            return "RECOVERED / CONTINUE MONITORING"
        return "RECOVERY WATCH / CONTINUE MONITORING"
    if sum(abs(current["groups"][name]["total"] / current["total"] -
               baseline["groups"][name]["total"] / baseline["total"]) for name in SLICES) >= 0.4:
        return "MIX SHIFT / INVESTIGATE"
    return "NORMAL / CONTINUE MONITORING"


def history():
    windows = {item[0]: window_records(*item) for item in WINDOWS}
    base = summarize("baseline", windows["baseline"])
    state = {"open": None, "streak": 0, "recovered": 0}
    audit = []
    for name, rows in windows.items():
        current = summarize(name, rows)
        # A simulated owner verifies the fix-day incident disposition before recovery.
        resolved = name.startswith("recovery")
        action = alert_step(base, current, state, resolved)
        audit.append({"window": name, "summary": current, "standard": standardized(base, current),
                      "action": action, "state": dict(state), "incident_resolved": resolved})
    return windows, audit


def monitoring_report(windows, audit):
    baseline = audit[0]["summary"]
    print("Controlled windows; all records synthetic")
    for record in audit:
        current = record["summary"]
        standard = record["standard"]
        adjusted = "n/a" if standard is None else f"{standard:.1%}"
        change = ("n/a" if standard is None else
                  f"{100 * (current['passed']/current['scored'] - baseline['passed']/baseline['scored']):+.1f} pp")
        groups = current["groups"]
        print(f"{record['window']}: {current['passed']}/{current['scored']} "
              f"({pct(current['passed'], current['scored'])}), missing={current['total']-current['scored']}; "
              f"routine {groups['routine']['passed']}/{groups['routine']['scored']} of {groups['routine']['total']}, "
              f"policy {groups['policy']['passed']}/{groups['policy']['scored']} of {groups['policy']['total']}; "
              f"baseline-mix {adjusted}; comparable raw change {change}; {record['action']}")
    lookup = {row["id"]: row for rows in windows.values() for row in rows}
    for cutoff in (6, 8):
        complete, arrived = available_feedback(cutoff, FEEDBACK)
        valid = [row for row in complete if lookup[row["request"]]["quality"] is not None]
        disagree = [row["event"] for row in valid if (row["label"] == "PASS") != lookup[row["request"]]["quality"]]
        print(f"Synthetic reviews at cutoff {cutoff}: {len(complete)} final of {arrived} arrived, "
              f"{len(FEEDBACK)-arrived} not arrived; disagreement events: {', '.join(disagree)}")
    print("Investigate:", "drop-3:policy:000", "critical:policy:000",
          "| owner: evaluation on-call, then authorization incident lead")


def export_langfuse(windows, audit):
    from langfuse import get_client, propagate_attributes

    required = ("LANGFUSE_BASE_URL", "LANGFUSE_PUBLIC_KEY", "LANGFUSE_SECRET_KEY")
    if not all(os.environ.get(key) for key in required):
        raise ValueError("Set the three Langfuse variables from M14-T01 before exporting")
    base = urlsplit(os.environ["LANGFUSE_BASE_URL"])
    if base.scheme != "http" or base.hostname not in {"127.0.0.1", "localhost", "::1"} or (
            base.username or base.password or base.path not in ("", "/") or base.query or base.fragment):
        raise ValueError("This export expects the loopback Langfuse Lite origin")
    client = get_client()
    feedback, _ = available_feedback(8, FEEDBACK)
    reviewed = {row["request"]: row for row in feedback}
    actions = {row["window"]: row["action"] for row in audit}
    selected = ("mix:routine:000", "drop-3:policy:000", "critical:policy:000", "recovery-2:policy:079")
    try:
        for identity in selected:
            name = identity.split(":")[0]
            row, = [item for item in windows[name] if item["id"] == identity]
            tags = ["synthetic-monitoring", row["version"][0], row["version"][1]]
            with client.start_as_current_observation(name="monitoring-replay",
                    input={"record": identity}, metadata={"window": name, "category": row["category"]}) as root:
                with propagate_attributes(tags=tags, metadata={"model_version": row["version"][0],
                                                               "prompt_version": row["version"][1]}):
                    with client.start_as_current_observation(name="inspect-quality", as_type="evaluator",
                            output={"quality": row["quality"], "signal": row["signal"],
                                    "receipt": row["receipt"]}):
                        pass
                root.update(output={"alert": actions[name]})
                if row["quality"] is not None:
                    client.score_current_trace(name="fixture_quality_pass", value=float(row["quality"]),
                                               data_type="NUMERIC")
                if identity in reviewed:
                    label = reviewed[identity]
                    client.score_current_trace(name="simulated_human_label", value=label["label"],
                                               data_type="CATEGORICAL", comment=label["issue"])
                print("Trace ID to look up after flush:", identity, client.get_current_trace_id())
    finally:
        client.flush()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--workbook", type=Path, default=WORKBOOK)
    parser.add_argument("--export-langfuse", action="store_true")
    parser.add_argument("--audit", type=Path, help="New file for the monitoring decision history")
    args = parser.parse_args()
    rows, stamp = historical(args.workbook)
    historical_report(rows, stamp, args.workbook)
    windows, audit = history()
    monitoring_report(windows, audit)
    if args.audit:
        decisions = [{**row, "summary": {**row["summary"], "versions": sorted(row["summary"]["versions"])}}
                     for row in audit]
        packet = {"provenance": "controlled synthetic windows", "rule": POLICY, "decisions": decisions,
                  "owner": "evaluation on-call",
                  "incident_events": [{"window": "critical", "status": "opened", "owner": "authorization lead"},
                                      {"window": "recovery-1", "status": "acknowledged and fix verified"},
                                      {"window": "recovery-2", "status": "closed after recovery check"}],
                  "workbook_sha256": hashlib.sha256(args.workbook.read_bytes()).hexdigest(),
                  "workbook_batch": stamp, "sampling_seed": SEED,

                                 for name, selected in samples(rows, 20, SEED).items()},
                  "synthetic_feedback": FEEDBACK}
        with args.audit.open("x", encoding="utf-8") as report:
            json.dump(packet, report, indent=2, sort_keys=True)
    if args.export_langfuse:
        export_langfuse(windows, audit)


if __name__ == "__main__":
    main()

### Decide what belongs in each queue

The population is the set you want to describe. Here it is the 49 workbook rows, and a sample of 20 is 40.8% of that set. Seed 14 makes reruns repeatable from the same sorted IDs and Python sampling implementation. In a real collector, deduplicate by request ID, preserve retry attempts separately, and decide the sampling unit before selecting rows. Use a stable ID and a deterministic random rule to avoid selecting only fast requests or only people who leave feedback.

- **Routine monitoring.** Simple random sampling gives all rows equal selection chance. This draw covers all five categories but tags 8/16 of the risk cases. For separate category estimates, stratify by request category or another declared traffic segment and keep model/prompt versions separate.
- **Balanced human review.** The stratified draw gives four cases to each of five categories. Its raw 60% is a sample statistic. Weight each category’s sampled human pass rate by its share of the workbook to estimate the original workbook mix. For Hallucination the weight is 11/49, even though that category supplies 4/20 of the sample. The resulting estimate is 57.1%. The archived labels have limitations, and a weighted sample estimates the workbook population under this sampling design.
- **Risk surveillance.** The risk draw deliberately includes all 16 rows tagged Prompt Injection, with the other four drawn from the remaining rows. It covers only three categories. Those tags are review priorities. The workbook does not prove these cases were critical production incidents. Always route an independently confirmed critical effect to the incident queue and use a separate failure-focused queue for exploratory review. Keep queue metrics and population estimates separate.

### Reconcile feedback and automatic verdicts

The 18 saved disagreements are concentrated in Hallucination (7) and Prompt Injection (6). ### Make the alert actionable

A window is one declared batch of observations. Require at least 20 scored policy requests, full policy-label coverage and at least 80% overall scored coverage for ordinary alerts. A 15-percentage-point or larger policy drop produces a watch, and two qualifying windows in a row produce a warning. The gap breaks the sequence. A mix check flags when the sum of absolute share changes is at least 40 percentage points. With two groups, that means a shift of at least 20 points in either group. Use a simple window chart in production with denominators, 50% baseline and 35% planning threshold marked. A statistical control chart requires limits estimated under a justified stable process and sample design. The thresholds here are engineering decision rules.
