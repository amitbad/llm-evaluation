## Optimize an LLM Application Under Cost, Latency and Reliability Constraints

### Define the comparison before measuring

Send the same burst of 40 Northstar requests to each profile. Baseline retries every failed model result up to two times. The selective profile retries only a transient failure or a timeout. Both have four workers, the same request order, 30 ms model-attempt deadline, synthetic token ledger and bounded jitter. A one-worker profile applies the selective rule to the same burst so you can see queueing under lower concurrency. It is a separate load comparison. Each profile runs and logs one warm-up before the burst.

Use these lab gates. Require at least 95% of all requests within 400 ms, at least 90% operational success and at least 85% confirmed task success across all submitted requests. Require strictly lower p95, fewer retries and lower fixture cost per confirmed task success. Compare every case’s operational result and quality verdict, and verify that the repeated write with an idempotency key leaves one ledger entry. A gate failure calls for investigation. The evidence supports only this fixture and load.

### Know what the clock measures

- **End-to-end latency** starts at submission and ends when the application has a result or a terminal failure. Queue time ends when a worker starts. Retrieval, model attempts, retry waits and tool execution have their own measured durations.
- **Evaluation time** is recorded separately. The worker does the fixture judge work after the response is ready, so it can still delay queued requests. The dataset also retains elapsed time including evaluation.
- **Elapsed time** comes from `monotonic_ns`, a clock suited to measuring intervals. A timed wait may resume after its requested deadline under scheduling pressure. Keep the requested budget and the actual duration separate.
- **Streaming metrics** need actual token or chunk arrivals. Time to first token starts at the declared request boundary and ends at the first usable token. An average time per output token after the first can be calculated as time from first to last token divided by remaining output tokens. These fixtures do not stream. TTFT, TPOT and network overhead are unavailable here. The model-call span measures the component wait, not decoder throughput.

### Run the lab

Use a local terminal from the repository root with Python 3.11 or newer. The benchmark and report use the standard library. Copy the Python block into `operational_lab.py` in a temporary directory. The code uses `ThreadPoolExecutor` to run requests in a bounded worker pool. Read the returned stage lists in sequence. `Decimal` computes fixture charges without binary floating-point rounding. `--write` measures and creates a new JSON file. `--read` reproduces the report from saved measurements.
```python
import argparse
from collections import Counter
from concurrent.futures import ThreadPoolExecutor
from copy import deepcopy
from decimal import Decimal
import json
import math
import os
from pathlib import Path
import platform
from random import Random
from threading import Event, Lock
from time import monotonic_ns
from urllib.parse import urlsplit

PRICING = {
    "version": "teaching-usd-per-million-v1",
    "unit_tokens": 1_000_000,
    "rates": {"fixture-agent-v1": ("1", "4"), "fixture-judge-v1": ("2", "8")},
    "infra_per_request": "0.000050",
}
APP = "northstar-component-fixture-v1"
TIMEOUT_MS = 30
MAX_ATTEMPTS = 3
FAMILY = [("normal", 24), ("slow", 4), ("transient", 3), ("timeout-once", 3),
          ("permanent", 2), ("exhausted", 2), ("unknown", 1), ("wrong", 1)]
RETRYABLE = {"transient", "timeout"}
SLO_MS = 400
FLOOR = {"operational": 0.90, "task": 0.85}
SCHEMA = "northstar-measurements-v1"


def charge(model, pricing, input_tokens, output_tokens, *, calls=1, retries=0, infrastructure="0"):
    """Token arguments are totals across all calls, including any retries."""
    values = (input_tokens, output_tokens, calls, retries, pricing["unit_tokens"])
    if (any(type(n) is not int or n < 0 for n in values) or not pricing["unit_tokens"]
            or retries > max(0, calls - 1) or (not calls and (input_tokens or output_tokens))
            or not pricing.get("version")):
        raise ValueError("Invalid usage or call counts")
    rates = list(map(Decimal, pricing["rates"][model]))
    extra = Decimal(infrastructure)
    if any(not n.is_finite() or n < 0 for n in (*rates, extra)):
        raise ValueError("Costs must be finite and nonnegative")
    return (input_tokens * rates[0] + output_tokens * rates[1]) / pricing["unit_tokens"] + extra


def ms(start, end=None):
    return ((monotonic_ns() if end is None else end) - start) / 1_000_000


def wait(milliseconds):
    Event().wait(milliseconds / 1000)


def stage(name, work_ms, **details):
    started = monotonic_ns()
    wait(work_ms)
    return {"stage": name, "ms": ms(started), **details}


def model_attempt(fault, number):
    status, work, tokens = "ok", 7, (400, 80)
    if fault == "slow":
        work = 24
    elif fault == "transient" and number == 1:
        status, work, tokens = "transient", 3, (0, 0)
    elif fault == "exhausted" or (fault == "timeout-once" and number == 1):
        status, work, tokens = "timeout", 50, (400, 10)
    elif fault == "permanent":
        status, work, tokens = "invalid-output", 23, (400, 80)
    # The local component stops waiting at its deadline. No background write continues.
    return stage("model", min(work, TIMEOUT_MS), status=status, attempt=number,
                 model="fixture-agent-v1", input_tokens=tokens[0], output_tokens=tokens[1])


def request(request_id, fault, submitted, selective):
    started = monotonic_ns()
    stages = [stage("retrieval", 3, version="documents-fixture-v1")]
    rng = Random(request_id)
    for number in range(1, MAX_ATTEMPTS + 1):
        attempt = model_attempt(fault, number)
        stages.append(attempt)
        if attempt["status"] == "ok":
            stages.append(stage("tool", 2, version="read-only-tool-fixture-v1"))
            break
        if number == MAX_ATTEMPTS or (selective and attempt["status"] not in RETRYABLE):
            break
        delay = 8 * 2 ** (number - 1) + rng.randrange(0, 4)
        stages.append(stage("backoff", delay, requested_ms=delay, after=number))
    finished = monotonic_ns()
    operational_ok = attempt["status"] == "ok"
    quality = None
    if operational_ok:
        stages.append(stage("evaluation", 3, model="fixture-judge-v1", input_tokens=240, output_tokens=20))
        if fault != "unknown":
            quality = fault != "wrong"
    return {"id": request_id, "fault": fault, "stages": stages, "queue_ms": ms(submitted, started),
            "e2e_ms": ms(submitted, finished), "including_evaluation_ms": ms(submitted),
            "operational_ok": operational_ok, "task_pass": quality,
            "quality_status": "unknown" if operational_ok and quality is None else
                              "not-evaluated" if not operational_ok else "scored",
            "final_status": attempt["status"], "terminal_timeout": attempt["status"] == "timeout",
            "retries": number - 1}


def suite():
    items = [fault for fault, count in FAMILY for _ in range(count)]
    Random(143).shuffle(items)
    return [(f"R{i:02}", fault) for i, fault in enumerate(items, 1)]


def run_batch(name, workers, selective):
    warmups = [request("warmup", "normal", monotonic_ns(), selective)]
    with ThreadPoolExecutor(max_workers=workers) as pool:
        pending = [pool.submit(request, case, fault, monotonic_ns(), selective) for case, fault in suite()]
        rows = [future.result() for future in pending]
    return {"name": name, "workers": workers, "selective_retries": selective,
            "warmups": warmups, "requests": rows}


def nearest_rank(values, percentile):
    if not values or not 0 < percentile <= 100:
        raise ValueError("Need observations and a percentile in (0, 100]")
    ordered = sorted(values)
    return ordered[math.ceil(percentile * len(ordered) / 100) - 1]


def request_cost(row, pricing):
    by_model = {}
    for component in row["stages"]:
        if "model" in component:
            total = by_model.setdefault(component["model"], {"input": 0, "output": 0, "calls": 0})
            total["input"] += component["input_tokens"]
            total["output"] += component["output_tokens"]
            total["calls"] += 1
    return Decimal(pricing["infra_per_request"]) + sum(
        charge(model, pricing, tokens["input"], tokens["output"], calls=tokens["calls"],
               retries=row["retries"] if model == "fixture-agent-v1" else 0)
        for model, tokens in by_model.items()
    )


def metrics(batch, pricing):
    rows = batch["requests"]
    n = len(rows)
    latency = [row["e2e_ms"] for row in rows]
    succeeded = sum(row["operational_ok"] for row in rows)
    passed = sum(row["task_pass"] is True for row in rows)
    scored = sum(row["task_pass"] is not None for row in rows)
    retried = [row for row in rows if row["retries"]]
    total = sum(request_cost(row, pricing) for row in rows)
    return {
        "n": n, "operational": succeeded, "task_pass": passed, "scored": scored,
        "unknown": sum(row["quality_status"] == "unknown" for row in rows),
        "mean": sum(latency) / n, "tail": [nearest_rank(latency, p) for p in (50, 90, 95, 99)],
        "slo_met": sum(value <= SLO_MS for value in latency),
        "p95_queue": nearest_rank([row["queue_ms"] for row in rows], 95),
        "retry_requests": len(retried), "retries": sum(row["retries"] for row in rows),
        "recovered": sum(row["operational_ok"] for row in retried),
        "timeout_attempts": sum(step.get("status") == "timeout" for row in rows for step in row["stages"]),
        "terminal_timeouts": sum(row["terminal_timeout"] for row in rows),
        "successful_tool_calls": sum(step["stage"] == "tool" for row in rows for step in row["stages"]),
        "total": total, "per_request": total / n,
        "per_operational_success": total / succeeded if succeeded else None,
        "per_success": total / passed if passed else None,
        "per_evaluated": total / scored if scored else None,
        "warmup_cost": sum(request_cost(row, pricing) for row in batch["warmups"]),
        "failures": dict(Counter(row["final_status"] for row in rows if not row["operational_ok"])),
    }


def repeat_write(use_key):
    ledger = []
    lock = Lock()
    recorded = {}

    def apply(key):
        with lock:
            if key is not None and key in recorded:
                return recorded[key]
            receipt = len(ledger) + 1
            ledger.append(receipt)
            if key is not None:
                recorded[key] = receipt
            return receipt

    key = "same-operation" if use_key else None
    apply(key)  # First call committed, but its acknowledgement was lost in the fixture.
    second = apply(key)
    return len(ledger), second


def decision(baseline, optimized, stats, candidate):
    left = {row["id"]: (row["fault"], row["operational_ok"], row["task_pass"]) for row in baseline["requests"]}
    right = {row["id"]: (row["fault"], row["operational_ok"], row["task_pass"]) for row in optimized["requests"]}
    if (baseline["workers"] != optimized["workers"]
            or {key: values[0] for key, values in left.items()} !=
               {key: values[0] for key, values in right.items()}):
        return "COLLECT MORE EVIDENCE"
    if left != right:
        return "REJECT CHANGE"
    if (candidate["tail"][2] > SLO_MS or candidate["tail"][2] >= stats["tail"][2]
            or candidate["operational"] / candidate["n"] < FLOOR["operational"]
            or candidate["task_pass"] / candidate["n"] < FLOOR["task"]
            or candidate["per_success"] is None or stats["per_success"] is None
            or candidate["per_success"] >= stats["per_success"]
            or candidate["retries"] >= stats["retries"] or repeat_write(True) != (1, 1)):
        return "INVESTIGATE FURTHER"
    return "ACCEPT CHANGE IN THIS FIXTURE"


def report(packet):
    if packet["schema"] != SCHEMA or packet["application"] != APP:
        raise ValueError("Unsupported measurement dataset")
    print("Environment:", packet["environment"])
    print("Pricing fixture:", packet["pricing"]["version"], "| one warm-up excluded per profile")
    stats = []
    for batch in packet["batches"]:
        row = metrics(batch, packet["pricing"])
        stats.append(row)
        print(f"{batch['name']} (workers={batch['workers']}): {row['n']} requests; mean {row['mean']:.1f} ms; "
              f"nearest-rank p50/p90/p95/p99 {'/'.join(f'{x:.1f}' for x in row['tail'])} ms; "
              f"queue p95 {row['p95_queue']:.1f} ms; within SLO {row['slo_met']}/{row['n']}")
        print(f"  Operational {row['operational']}; task pass {row['task_pass']}; scored {row['scored']}; "
              f"unknown {row['unknown']}; successful tool calls {row['successful_tool_calls']}; "
              f"retried {row['retry_requests']}; retries {row['retries']}; recovered {row['recovered']}; "
              f"timeouts {row['timeout_attempts']} attempts / {row['terminal_timeouts']} terminal")
        monetary = (row["total"], row["per_request"], row["per_operational_success"],
                    row["per_success"], row["per_evaluated"], row["warmup_cost"])
        print("  Fixture USD total/request/operational success/task success/evaluated/warm-up:",
              " / ".join(f"{value:.6f}" if value is not None else "n/a" for value in monetary),
              "| final failures:", json.dumps(row["failures"], sort_keys=True))
    print("Lost acknowledgement without / with idempotency (writes, last receipt):",
          repeat_write(False), "/", repeat_write(True))
    print("Decision:", decision(*packet["batches"][:2], *stats[:2]))


def measure():
    return {"schema": SCHEMA, "application": APP, "pricing": deepcopy(PRICING),
            "environment": f"{platform.system()} {platform.machine()}, Python {platform.python_version()}",
            "clock": "monotonic_ns", "attempt_timeout_ms": TIMEOUT_MS,
            "batches": [run_batch("baseline", 4, False), run_batch("selective", 4, True),
                        run_batch("serial workers", 1, True)]}


def export(packet):
    origin = urlsplit(os.environ.get("LANGFUSE_BASE_URL", ""))
    if (origin.scheme != "http" or origin.hostname not in ("127.0.0.1", "localhost", "::1")
            or origin.username or origin.password or origin.path not in ("", "/")
            or origin.query or origin.fragment
            or not all(os.environ.get(key) for key in ("LANGFUSE_PUBLIC_KEY", "LANGFUSE_SECRET_KEY"))):
        raise ValueError("Use the configured loopback Langfuse Lite lab")
    from langfuse import get_client

    client = get_client()
    try:
        for batch in packet["batches"][:2]:
            selected = ("normal", "timeout-once", "permanent", "exhausted", "wrong")
            for fault in selected:
                row = next(item for item in batch["requests"] if item["fault"] == fault)
                with client.start_as_current_observation(name="northstar-operational-replay",
                        input={"request_id": row["id"]}, metadata={"profile": batch["name"],
                        "environment": packet["environment"], "application": packet["application"],
                        "measured_e2e_ms": row["e2e_ms"], "measured_queue_ms": row["queue_ms"],
                        "pricing": packet["pricing"]["version"], "provenance": "local-fixture-replay"}) as root:
                    for step in row["stages"]:
                        kind = {"model": "generation", "evaluation": "evaluator",
                                "retrieval": "retriever", "tool": "tool", "backoff": "span"}[step["stage"]]
                        extra = {}
                        if kind == "generation":
                            extra = {"model": step["model"], "usage_details": {"input": step["input_tokens"],
                                      "output": step["output_tokens"]}}
                        metadata = {key: value for key, value in step.items() if key != "stage"}
                        with client.start_as_current_observation(name=step["stage"], as_type=kind,
                                level="ERROR" if step.get("status", "ok") != "ok" else "DEFAULT",
                                metadata=metadata, **extra):
                            pass
                    if row["task_pass"] is not None:
                        client.score_current_trace(name="fixture_task_pass", value=float(row["task_pass"]),
                                                   data_type="NUMERIC")
                    root.update(output={"operational_ok": row["operational_ok"], "retries": row["retries"],
                                "task_pass": row["task_pass"], "fixture_usd": str(request_cost(row, packet["pricing"]))})
                    print("Trace to verify after flush:", batch["name"], row["id"], client.get_current_trace_id())
    finally:
        client.flush()


def main():
    parser = argparse.ArgumentParser()
    mode = parser.add_mutually_exclusive_group(required=True)
    mode.add_argument("--write", type=Path, help="Measure and save to a new JSON file")
    mode.add_argument("--read", type=Path, help="Recompute the report from saved measurements")
    parser.add_argument("--export-langfuse", action="store_true", help="Replay selected traces to loopback Lite")
    args = parser.parse_args()
    if args.write:
        with args.write.open("x", encoding="utf-8") as handle:
            packet = measure()
            json.dump(packet, handle, separators=(",", ":"), allow_nan=False)
    else:
        packet = json.loads(args.read.read_text(encoding="utf-8"))
    report(packet)
    if args.export_langfuse:
        export(packet)


if __name__ == "__main__":
    main()
```

### Follow the slow requests

Nearest-rank p95 sorts the times and selects the value at rank `ceil(0.95 × n)`, starting at rank 1. With 40 requests, p95 is rank 38 and p99 is the maximum. The p99 is an observed order statistic in this small burst. It says little about rare delays in production.

The selective mean was 179.1 ms, while p95 was 308.5 ms. Queue p95 was 284.2 ms. Look up a complete request before blaming the model. Selective R20 spent 170.1 ms queued and finished in 201.3 ms. Baseline R20 retried the same permanent malformed output twice and finished in 294.9 ms. The median moved from 190.7 ms to 191.0 ms, so the improvement showed up mainly in the tail of this run. The one-worker burst used the same selective rule and work but reached just 9/40 within the time objective. Measure queue depth and wait before increasing concurrency. A local fixture that mostly waits is cheaper to run in parallel than a real service contending for limited inference resources.

### Trace the failure and the retry decision

The faults are part of the frozen request schedule. Use each named case to verify the policy in your saved JSON. To run only the comparison, leave the workload constant. To test the response to a different failure, change one class count in `FAMILY` in a scratch copy, write to a new file, and keep that experiment separate from the recorded comparison.

| Inspect | Fault and observed result |
| --- | --- |
| R11 | The first model attempt fails transiently before any tokens are counted. A bounded wait precedes a successful retry |
| R13 | The first attempt hits the cooperative deadline. The second completes. The trace retains both attempts |
| R20 | Both profiles still fail on malformed output. Selective avoids two attempts and two waits |
| R08 | The timeout persists through all three attempts. The request ends with a terminal timeout |
| R01 and R27 | Both are operational successes. R01 fails evaluation. R27 has no final correctness label |

The exercise’s retry waits are 8–11 ms, then 16–19 ms, using a seed per request. Exponential backoff increases the wait, jitter spreads competing retries, and the attempt cap prevents unbounded work. The injected timeout cancels waiting inside this fixture. A real client deadline does not establish cancellation at a remote provider.

For a real request, retry a known transient network problem only within a shared deadline and budget. Treat rate limits according to provider instructions, including Retry-After where present. Preserve and classify partial responses or ambiguous tool acknowledgements. Correct invalid parameters, incompatible context length, permission failures or malformed output before resubmitting. For an unavailable tool, consider a safe fallback and an operator alert. Bound concurrency and total retries so one slow dependency does not fill the queue and amplify failure across services.

For the write demonstration, the first action commits but the acknowledgement is treated as lost. Repeating without a key creates a second ledger entry. An atomic check and write under the same key returns the first receipt and leaves one entry. In a real backend, use a durable operation key scoped to the caller and operation, bind it to the payload, and verify the final state. This demonstration exercises only an in-memory ledger.

### Account for all the work

The pricing record `teaching-usd-per-million-v1` is fictional. It charges the fixture agent $1 per million input tokens and $4 per million output tokens, the fixture judge $2 and $8, and adds $0.000050 per request. The model and evaluation token counts here are inputs to the fixture. Actual APIs may return per-attempt usage. An unreported count after a timeout is unknown and needs reconciliation. Local inference may have no API token invoice, but compute, energy, hosting and review still cost money.

A normal request costs `(400 × 1 + 80 × 4) / 1,000,000 = $0.000720` for the agent and `(240 × 2 + 20 × 8) / 1,000,000 = $0.000640` for the judge. Add infrastructure for `$0.001410`. On a timeout-then-success case, the failed attempt adds `(400 × 1 + 10 × 4) / 1,000,000 = $0.000440`. Include both calls even though only one returned a usable result. To price another recorded model, use its model ID, pricing version, unit, and measured tokens over all its calls. The retry count describes those calls. It does not multiply token totals a second time. Keep cached tokens, batch rates and provider tool charges separate if your approved price sheet distinguishes them.

The report divides all measured requests’ fixture spend by 40 for cost per request, 36 for cost per operational success, 34 for cost per confirmed successful task and 35 for cost per evaluated request. Evaluation spend and failed work stay in every numerator. Warm-up cost is reported separately. In a multistep agent, sum each generation and judge call plus verified tool or infrastructure charges. A shorter prompt or a smaller model is a new comparison that must retain quality and safety gates.

### Read the reliability denominators, then decide

An operational success is a usable response from the application. A scored failure can still return successfully at the transport layer. Of 40 requests, 36 succeeded operationally and 34 passed the task. The scored pass rate is 34/35. One usable response is unscored, so it stays unknown in the audit. The lab uses 34/40 confirmed task passes for its guardrail. There are 36 successful tool calls out of 36 attempted, because the fixture skips the tool on model failure. The terminal timeout rate is 2/40, separate from nine timed-out attempts. Retry-request rate moves from 10/40 to 8/40, and six retried requests recover in each profile.

A service-level indicator is a measured rate, such as all requests finishing in 400 ms or less. A service-level objective states its target. A 95% latency SLO permits two misses in this 40-case batch, an error budget separate from the operational failure budget. The saved selective run met the latency, operational and task floors. It preserved every case outcome, cut four retries, reduced p95 from 346.8 to 308.5 ms, and reduced fixture spend by $0.002880. **Accept the selective rule for this fixture.** Collect repeated load runs and measured provider usage before a wider deployment. If the quality guard fails or useful recoveries disappear, investigate or reject the change. A deployed regression needs the release policy and evidence from [Release decisions, rollback and governance](#m13-t03).

## Worked Solutions to Practice

The selective rule keeps six recoveries and all per-case outcomes while lowering p95 and confirmed-task cost from $0.001742 to $0.001658. R20 shows exactly why. Its repeated malformed results are eliminated without changing the failure verdict. Accept selective retries for this fixture. The one-worker burst preserves the quality and cost results, but p95 reaches 1233.0 ms and 31/40 requests miss the SLO. Reject that capacity configuration for this burst. Retest under representative arrivals with real inference, usage and timeout data. Check p95 over multiple batches before trusting the observed difference.

## Common Mistakes

- If the report cannot find the fixture, run from the repository root. Recompute the supplied JSON before comparing your machine’s timing.
- If `--write` says the file exists, choose a new name. Keep the previous run and its environment metadata.
- If Lite does not show a trace, verify the URL, database and trace ID after flush. Compare the measured elapsed metadata instead of the exporter’s wall-clock duration.
- Stop the Lite server with Ctrl+C. Keep your scratch directory and viewer only as long as needed. Unset the three Langfuse variables when finished.
