Your Evaluation
Learning Journey

A hands-on guide for QA Engineers and Test Architects moving into GenAI evaluation. Every concept is taught through a real exercise — you build it, run it, and understand why it behaves the way it does.

How to use this documentation: Use the left sidebar to navigate between tests. Each test page documents what was built, what was run, the actual results, and the key learnings. Read Concepts Reference whenever a term is unfamiliar.
Model providers: All scripts run on local models via Ollama by default — free, no account needed. To use a paid model (OpenAI, Anthropic, Gemini) as bot or judge, change BOT_PROVIDER or JUDGE_PROVIDER in config.yaml. Bot and judge can use different providers. See .env.example for API key setup.
